Proceso de Liquidación

Para ver las liquidaciones de un período específico, haga clic en la tarjeta correspondiente. Cada período contiene la configuración específica para ese mes:

  • Valores de UF y UTM: Actualizados según el período
  • Días hábiles: Configurados para cálculos de haberes
  • Factor de actualización: Para reajustes salariales
  • Fechas: Definidas para el período de liquidación

Estados del Período

ACTIVO Período disponible para liquidar
CERRADO Liquidación completada
PROCESADO En proceso de cálculo
INACTIVO Período no disponible

Ayuda - Panel de Liquidaciones

1. Seleccionar Período: Haga clic en cualquier tarjeta de período para acceder a sus liquidaciones.

2. Filtrar: Use los filtros superiores para buscar períodos específicos.

3. Estados: Los períodos pueden estar en diferentes estados (ACTIVO, CERRADO, etc.).

4. Información: Cada tarjeta muestra información clave del período como UF, UTM y días hábiles.
